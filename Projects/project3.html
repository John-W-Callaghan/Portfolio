Project Explained

This project involved building a custom portfolio website using HTML, CSS, and JavaScript to showcase my skills, projects, and achievements. I created multiple pages with a user-friendly navigation system and added an animated background for a more dynamic feel. Below, I outline the key steps I followed in building this project:

1. Structuring the Website with HTML: I started the project by building a clear, multi-page layout using HTML. My goal was to create pages for all key sections: "Home," "Projects," "About Me," "Achievements," and "Experience." I wanted the navigation to be consistent across all pages, so I used a reusable header and navigation bar. This allows users to easily move between different sections of the website without hassle.

2. Styling the Website with CSS: For the visual design, I used CSS to ensure the site looked clean and professional. I focused on keeping the color scheme simple and easy on the eyes, using dark shades for the background and contrasting colors for the text. I also designed the layout to be responsive, so it adjusts well across different screen sizes, making it accessible on both desktop and mobile devices.

3. Adding an Animated Background with JavaScript: To make the website more interactive and visually appealing, I implemented an animated particle background using JavaScript. This feature involves creating particles that move randomly across the screen, adding a dynamic layer to the background while keeping it subtle enough not to distract from the content.

4. Navigating Between Pages: To ensure easy navigation, I created a fixed navigation bar at the top of the page, linking to all the main sections of my portfolio. Each link allows the user to seamlessly transition between pages like "Projects" and "Experience." This structure makes the website intuitive, giving visitors quick access to the information they're looking for.

5. Showcasing My Work and Achievements: I added specific sections to highlight my achievements, projects, and experience. Each project and achievement is presented with a brief description and an image to make it visually engaging. For instance, my Python certifications and data science achievements are displayed with certificates and detailed explanations of the skills I gained.

6. Final Thoughts: Building this portfolio website allowed me to combine both technical and design skills. From coding the animated background to structuring content effectively, I’m really pleased with how the site turned out. It’s fully responsive, user-friendly, and serves as a showcase for my skills and experiences.
