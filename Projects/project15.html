Project Overview - Still in progress

The primary goal of this project is to develop software capable of accurately identifying characters from the Odia alphabet. This will be achieved using neural networks, specifically a Convolutional Neural Network (CNN), which excels in recognizing complex patterns in data. However, due to the lack of large datasets for Odia script, an alternative approach is necessary.

To address this challenge, transfer learning is employed. A script with structural similarities to Odia such as Bangla, allowing the model to leverage pre-existing knowledge from a different dataset. This approach enables the model to learn effectively despite the limited data available for Odia character recognition.
