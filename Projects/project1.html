Project Explained

This project involved building a custom search engine for video games, using HTML files as the dataset for my information retrieval module at university. The process covered several steps, from extracting data to implementing TF-IDF for handling search queries.

1. HTML File Reading: I began by reading each HTML file from a specified folder using a function called `Htmlread`. This function utilized BeautifulSoup to parse the HTML structure, extract the title and main content from each file, and return the information in a dictionary format. I also stored the file paths for easy reference during searches.

2. Extracting Main Description: I created a `description` function to identify and extract the main description of each game. It searches for specific comment tags like `DESCRIPTION ` and `/DESCRIPTION` in the HTML files to isolate the section that describes the game, ensuring only relevant information is captured.

3. Query Preprocessing: To enhance the effectiveness of the search results, I used the `preprocess_query` function. This function tokenizes the input query, removes punctuation, and expands the query using synonyms from the WordNet corpus. Expanding queries in this way increases the flexibility and relevance of the search.

4. Tokenization and Lemmatization: The core part of the project was processing the text content of each HTML file through the `tokenizor` function. This function tokenized the text, removed punctuation, converted everything to lowercase, applied lemmatization (reducing words to their base forms), and removed stopwords. I also gave extra weighting to titles and headings within the content to boost the relevance of those sections during searches.

5. TF-IDF Vectorization: After processing the text, I used the `TfidfVectorizer` from scikit-learn to convert the text data into a numerical matrix. This matrix assigns importance to words based on their frequency within the corpus, enabling me to compare queries and documents using cosine similarity.

6. Search Functionality: I implemented a `search` function that takes user queries, processes them, and compares them to the TF-IDF matrix. The function ranks documents based on their relevance to the query, returning the top results, including the title, description, and file name. Cosine similarity ensures the most relevant documents are ranked first.

7. Displaying Results: The final step was to format the search results for each query. Each result includes the title and description of the corresponding HTML file, making it easy for users to identify the games they are interested in.
