Project Explained

This project demonstrates how I used Natural Language Processing (NLP) techniques to predict emotions from text. I built a simple user interface for emotion prediction using logistic regression. Below, I describe the main steps I followed in this process:

1. Tokenization and Preprocessing: First, I defined a function called `tokenize`, which processes the text input by converting it to lowercase and splitting it into individual tokens (words). The function also removes punctuation and stopwords, and it applies stemming using NLTK’s `PorterStemmer` to reduce words to their base form. This preprocessing step was essential to convert raw text into a more manageable format for analysis.

2. Data Loading and Preprocessing: I loaded a CSV file containing text data with corresponding emotion labels. For each sentence in the dataset, I applied the `tokenize` function to preprocess the data. This ensured that each sentence was ready for feature extraction.

3. Train-Test Split: After preprocessing the data, I split the dataset into training and testing sets using scikit-learn's `train_test_split` function. This allowed me to build and evaluate the model effectively. In this setup, the text data (X) represents the sentences, and the labels (y) correspond to the emotions.

4. Vectorization: To convert the text into numerical features, I used `CountVectorizer`, which transforms the text data into a matrix of token counts. This step created feature vectors based on word frequencies, which I used as input for the machine learning model.

5. Logistic Regression Model: I trained a logistic regression model to classify sentences into different emotion categories, such as sadness, joy, love, anger, fear, and surprise. Once trained on the dataset, the model predicted emotions for the test data, and I calculated the accuracy score to measure its performance on unseen data.

6. Emotion Prediction Function: I created a function called `predict_emotion` to take any input sentence, preprocess it using the `tokenize` function, vectorize it with `CountVectorizer`, and then predict the emotion using the trained logistic regression model. The function then mapped the predicted label to the corresponding emotion.

7. Graphical User Interface (GUI): I built a simple GUI using Tkinter, a Python library for creating desktop applications. The GUI allows users to input a sentence, click the "Predict Emotion" button, and view the predicted emotion in real-time. The interface includes input fields and buttons to make it user-friendly.

8. Running the Application: The final step involved running the Tkinter-based application. When a user enters a sentence and clicks the predict button, the application processes the sentence and displays the predicted emotion on the screen. This interactive feature makes the model accessible and easy to test with various inputs.
